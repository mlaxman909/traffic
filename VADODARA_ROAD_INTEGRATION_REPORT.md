## Problems Found

1. Alembic autogenerated migration had extra changes to existing tables — rewritten to additive-only.
2. JSONB insert with `::jsonb` cast failed with psycopg2 — fixed to use `CAST(:geometry_json AS jsonb)` with JSON-serialized string.

## Limitations

1. No PostGIS — geometry in JSONB, no spatial queries
2. No road-to-traffic linkage — kept deliberately separate (correct approach)
3. OSM name coverage only 2%
4. SVG coordinate projection is linear approximation
5. Frontend loads major roads only (~1,600 of 45,903) for performance
